# BRM Tracker

Free platform for Indian randonneuring clubs to run brevets, track riders with almost no rider effort, and let the public follow along.

## Product plan

See **[docs/PRODUCT_PLAN.md](docs/PRODUCT_PLAN.md)** for goals, audience requirements, privacy approach, proposed free-tier stack, data model outline, roadmap, and risks.

This repository currently holds the product plan. Application code will follow once the plan is agreed with a pilot club.
